Контакты сервисной службы

Подставляются в ответ, когда в руководствах нет нужного раздела: механик должен понимать, куда звонить. Пока поля пусты, вместо контактов выводится заглушка.

Пороги отказа

Чем выше порог, тем чаще сервис честно отказывается вместо ответа «рядом по теме». Значения подобраны на демонстрационном корпусе; после загрузки заводских руководств их стоит проверить на тестовом наборе.

LLM-режим

По умолчанию выключен: сервис отвечает дословными цитатами. Ключ доступа в файл настроек не пишется — он задаётся переменной окружения SILANT_LLM_API_KEY.

Полный JSON

Продвинутый режим: правила уточнения модели и границы применимости базы. Правки проверяются перед записью: некорректный конфиг сохранить нельзя.
