# Куда класть руководства

Этот каталог — и есть хранилище исходных руководств. Отдельной операции загрузки
нет: файл, положенный сюда, считается загруженным. Дальше работа идёт в контейнере:
Python и poppler на хосте не нужны.

Если файлы уже лежат в каталоге, повторно загружать ничего не нужно. Проверить,
что сервис их видит:

```bash
docker compose exec silant-assistant python3 -m app.ingest --list
```

Команда выводит документы с числом страниц и фрагментов. Повторная индексация
нужна только в трёх случаях: добавлен новый файл, заменена редакция существующего,
изменены правила разбора.

```bash
./deploy.sh --reindex        # перезапуск и индексация с заменой изменённых
```

Если контейнер уже работает и перезапуск не требуется:

```bash
docker compose exec silant-assistant python3 -m app.ingest \
  --dir /app/data/documents --db /app/data/index.sqlite3
docker compose exec silant-assistant python3 -m app.ingest --list   # проверка
```

Требования к файлам:

- текстовый слой PDF (не скан). Для сканов нужен OCR: `ocrmypdf --skip-text in.pdf out.pdf`;
- имя файла латиницей или кириллицей, без пробелов желательно: из него строится `doc_id`;
- после загрузки проверьте число разделов и таблиц командой `--list`.

Без Docker (только разработка): `python3 -m app.ingest`, затем
`python3 -m app.server --open`. Порядок описан в README, раздел
«Развёртывание без Docker».

PDF в репозиторий не коммитятся: каталог исключён в `.gitignore`.
